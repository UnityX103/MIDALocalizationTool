# MIDA 本地化编辑器 0.3.1

## 下载与安装

- macOS：`MIDA-Localization-0.3.1-macOS-universal.dmg`，支持 Apple Silicon / Intel，最低 macOS 13。
- Windows：`MIDA-Localization-0.3.1-Windows-x64-setup.exe`，适用于 Windows 10 / 11 x64；缺少 WebView2 时安装程序会联网下载。
- 已安装 0.3.0 的用户可以启动应用检查更新，或在偏好中手动检查。安装前自动保存并备份。
- `.app.tar.gz`、`.sig`、`latest.json` 用于签名自动更新，无需手动安装。

## 本次更新

- 偏好新增「清空所有的缓存」，二次确认后删除所有语言空间的数据、草稿、历史备份和视频缓存；取消不清理，不删除原始 ZIP 或已导出的文件。
- 导入其他语言包时询问是否创建或切换对应语言空间，确定后自动导入并切换，取消保留原空间。
- 导入覆盖前先备份被覆盖空间，备份失败停止覆盖。
- 历史记录支持只读查看，包括未确认草稿；返回最新版本后才恢复编辑。
- 回退历史需要二次确认，并先备份当前最新内容；回退成功后才允许编辑。
- 切换到「全部对话」、恢复该视图或导入新包后，对话包默认全部收起，仍可手动展开。

## 注意事项

- 历史仍保留最近 10 份备份；已删除的旧视频不会随历史回退恢复。
- macOS 使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证；Windows 未进行 Authenticode 签名，系统可能提示来源或发布者未知。更新包沿用 0.3.0 的 Ed25519/minisign 签名密钥。
- Windows 安装包在 macOS 交叉构建，未在真实 Windows 系统执行安装或启动验证。
- 沿用现有发布方式：不自动提交本地源码，Release 标签指向远端现有 main。准确构建源码见 source.tar.gz 附件；build-info.json 记录源码及产物哈希，SHA256SUMS 用于核对下载。
- 不包含用户 ZIP、视频、工作区、依赖缓存或私钥。
