# 本地化 ZIP 交付边界

本编辑器不直接读取 Unity 工程。Unity 导出 ZIP，编辑器导入并编辑，再导出数据 ZIP 给 Unity 回收。

## 清单与片段

ZIP 根目录为 `manifest.json`，每个片段分别位于 `parts/<partName>.json`。同片段的多个目标语言任务可放在同一片段文件中，不将全部片段合并为一个数据文件。

- 纯数据包使用清单 v2。
- 附带预览视频的输入包使用清单 v3，同一片段包含 `previews/<partName>/video.mp4` 和 `previews/<partName>/dialogue-map.json`。
- 媒体必须成对，片段和 recordingId 必须一致。清单记录路径、SHA-256、byteLength 及共同版本标识。
- 内部对话数据保留 `mida-localization` v1 格式、projectId、packageId、fileVersion 及来源哈希；清单版本与内部对话格式版本不是同一概念。
- 导出只包含选择交付的任务，生成数据清单 v2 和每片段 JSON，不回传视频。

解析实现以 `package_io.py`、`src-tauri/src/package.rs` 和前端导入校验为准。未知资产、旧单文件清单 v1、示例任务、不安全路径及清单外文件被拒绝。

## 版本合并

### 词条来源快照（只读）

- `currentSource`：最新正式中文原文。
- `localizationSourceAtExport`：同 key 本地化表 `origin_text` 的旧中文，缺失为空串。展开对话包时，有非空白内容才显示「旧本地化中文」整块；与最新原文相同也显示，空串或纯空白连标题一起隐藏。收起后的摘要只使用最新原文和目标译文，不包含旧中文。
- `translationAtExport`：导出前所选目标语言的译文，不一定是英文。
- 可选 `englishTranslationAtExport`：同 key 本地化表 `text_en` 的旧英文，与任务语言无关，缺行或缺列时显式为空串。缺少该字段的旧包仍可导入；兼容读取仅在 `en` 任务使用 `translationAtExport`，其他语言返回空串。显式空串不触发回退，不使用可编辑 `translation` 回填。
- `translation` 仍是可编辑目标译文。编辑、确认、自动保存、备份、历史回退和再导出均保留来源快照；不会把最新原文、旧工作区原文或目标译文写成旧中文。旧存档中的 `previousSource` 不再用于显示旧本地化中文，新合并不再生成此别名。
- 有新任务版本时保留新包提供的快照；同任务版本且原有哈希和该词条三个来源快照一致时，可按 key 补充此前缺失的 `englishTranslationAtExport`，保留本地译文、草稿和复核状态，不覆盖已经存在的旧英文快照。
- 旧包缺少的可选字段在持久化与再导出中保持缺省，兼容读取不会修改原始字段。新增字段只接受字符串（含空串），拒绝 null、数字或对象。ZIP / manifest 版本不变，仍每片段一份 JSON；不增加旧英文对比界面。

同一项目、同一片段、同一语言且 key 相同的词条可匹配。当前中文与用户处理过的中文基线一致时复用译文；不同则保留已有译文并标记待处理，避免新包覆盖未交付的编辑成果。用户点「确定」后回到预览状态。

传入的版本身份由 ZIP 提供，不生成占位项目或伪造来源版本。首次启动不内置任何任务，空白工作区不能导出。

## 预览媒体

时间映射使用 `mida-localization-preview` v1；事件含包名、occurrence、frame 和 timeMs。包名按 UTF-8 字节词典序排序并去重，对紧凑 JSON 数组计算 SHA-256。完整有效包清单与实际录到的包清单分别保存，不把未覆盖分支当作版本落后。

播放器位于窗口底部；只有片段视频可用且包含目标对话包节点时显示「查看视频」。编辑器不录制或导出视频。

新任务导入成功后，清除同项目同片段旧媒体；新包不含视频时同样清理。取消或保存失败不清理旧媒体，其他片段不受影响。备份保留媒体引用而不复制视频，被清理的旧视频不能通过备份恢复。

## 容量与安全

- 文本单文件不超过 64 MiB，总计不超过 128 MiB。
- 视频单文件不超过 512 MiB；ZIP 压缩及解压总量不超过 2 GiB。
- 最多 100 个片段、301 个 ZIP 条目、1000 个语言任务、100000 条对话。
- 拒绝路径穿越、重复路径、符号链接、加密包、不匹配的哈希与清单外文件。
- 浏览器服务仅监听本机并校验 Host / Origin；桌面端通过原生文件选择器或拖入 ZIP 获取输入。

自动保存是本机恢复机制，不代替独立设备备份。交付前仍应保留导出的 ZIP。
