# 国内更新镜像的可用性

镜像保留 CNB 的 Issue 反馈配置与 GitHub 的发布历史。两端 main 已合并历史，后续同步仍使用普通快进推送，不强制覆盖任何远端。

GitHub Release API 返回 403 / 429 / 服务错误或网络不可用时，镜像读取本项目官方 `releases/latest` 的最终地址，确认最新正式版本。
只接受固定 GitHub 项目中的 `v主.次.补丁` 标签，并检查标签提交属于 GitHub main、源码应用版本与标签一致；其他 API 格式错误仍直接失败。
回退不需要新增 GitHub token，也不会把 GitHub 私钥或访问凭据传入 CNB。

附件名称沿用既有 CD 约定，元数据 / 签名最多 4 MiB，其他资源最多 512 MiB。
同时检查声明长度和实际接收字节；全部资源继续核对 SHA256SUMS，构建提交、标签、源码哈希与更新策略也保留原有校验。
安装包及签名按 GitHub 云构建原始字节上传，附件全部完成后才正式发布。

正式安装包仍由 GitHub Actions 生成，镜像只下载、校验和转发。GitHub 与 CNB 已发布的同版本不会覆盖重传。
