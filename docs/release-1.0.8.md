# MIDA 本地化编辑器 1.0.8

- 当前存档损坏时仍可查看有效备份、恢复或切换健康空间；恢复前单独保护原始数据。
- 导入前检查整个空间的总容量；浏览器已有超限存档可按完整片段拆分恢复，不静默截断内容。
- 损坏备份单独隔离，避免阻断健康内容的保存与交付；清理保留恢复原件和归档引用。
- 浏览器视频导入增加事务登记、续租和遗留暂存回收，保护已经持久化但尚未完成的媒体提交。
- 新增“工作量归档与继续生产”，保留累计字数、去重记录和历史待交接状态；归档可导出固定 ZIP 与完整台账 JSON。
- 词条列表分页，减少大任务确认时的重绘与传输；确认按队列顺序提交，候选译文保存成功后才更新显示。
- 更新 Tauri 与 rustls 安全补丁；更新元数据限制 4 MiB、安装资源限制 512 MiB，保留原有签名校验。

本版为可选更新。已通过前端语法 / 生成及 Rust 编译检查；真实大任务、损坏恢复和双端实际安装更新尚未完成专门运行验收。
