# MIDA 本地化编辑器 1.0.12

- 修复旧版存档兼容问题：已有工作区和历史备份中的录像只读备注保持原值，不因旧备注格式阻止恢复或继续保存；新 ZIP 仍严格校验来源身份、哈希和录像映射。
- ZIP 导入按目标语言自动创建并进入对应空间，原有语言空间继续保留。新增“导入 ZIP”按钮，支持系统文件选择和原有拖入方式。
- 支持 ZIP 录像映射中的 `sourceHash`、`recordedAtUtc` 可选只读字段，保留 `tc` 与 `zh_tw` 各自的语言代码和空间。
- 更新描述优先读取 GitHub，网络不可用时回退 CNB；安装包优先从 CNB 下载，失败后尝试 GitHub，同一目标版本始终使用同一签名校验。安装前先保存当前编辑内容。

本版为可选更新。沿用正式版原有存储目录、存档格式与更新签名密钥，不迁移或清空任务、译文、草稿及台账。导入新任务 ZIP 仍按原规则替换同片段的预览视频；新包未携带的同片段旧视频会被清理，历史备份不恢复视频。

本地完成语法、版本一致性、前端生成与 Rust 编译检查；安装包由 GitHub Actions 重新构建。尚未完成 Windows 实机升级验收。
