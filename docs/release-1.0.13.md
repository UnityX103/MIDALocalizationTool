# MIDA 本地化编辑器 1.0.13

- 更新各语言空间的翻译计数与验收口径：唯一扩展为非空白全角字符计 1 词，数字作为整体计数，其余词数规则依据 GMX-V 2.0。规范折算保留精确分数，需要单独计字符的文字另行汇总；已有记录读取后按新口径重计。
- 新交付使用 `mida-gmx-fullwidth-v2`，同步桌面端、浏览器端与验收工具；保留旧版工作记录身份、冻结交付、归档及回执兼容。外部接收端需要支持新规则后才能按相同口径验收。
- 新增底部「导出 Excel」入口：将当前语言空间勾选片段的全部对话导出到一张表，保留原文、译文、完整 key、下标、换行与空译文，各片段以标题行分隔。
- Excel 同时汇总留存台账、归档、备份和来源快照中的历史译文，按「使用中」「已被覆盖」「已弃用」标记状态，旧内容以浅灰底显示，支持表头筛选。仅只读汇总现有留存内容，不恢复工作区，也不改变交付状态。

本版为可选更新。保留各语言空间、任务、译文、草稿、台账与备份；历史冻结原件保持原值，新导出按当前规则生成。Excel 仅供查看与校对，不支持回导。

安装包由 GitHub Actions 重新构建。本地检查覆盖语法、版本一致性、前端生成与 Rust 编译；尚未完成 Windows 实机升级及外部接收端联调验收。
