# MIDA 本地化编辑器 1.0.6

- 左下角新增当前中文翻译进度与累计翻译字数。悬停查看口径，点击问号查看 ZIP 根目录 `manifest.json` 中的对账字段。
- 交付包保留独立版本、逐笔工作量、待交接量、相对上一包新增量和来源更新后的工作量；重复导出不清零，中文更新或删除不抹去已完成劳动。
- 配合支持工作量协议的 Unity 端，下一次来源包自动携带接收回执，导入后确认上次交接，无需另交验收文件。
- 已确认句子可再次编辑。同中文润色不重复计数，跨版本保留的未确认草稿在首次确认时正确计量。
- 对导出重试、保存失败、回执去重与交付身份冲突增加校验。功能启用前的历史劳动不推算，界面统计仅供辅助，以交接清单为准。
