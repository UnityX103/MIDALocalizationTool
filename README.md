# MIDA 本地化编辑器

独立的 macOS / Windows 桌面本地化编辑项目，使用 Tauri 2、HTML/JavaScript 和 Rust。当前源码版本 **0.3.0**；应用通过 ZIP 与 Unity 交换数据，不依赖 Unity 工程目录、Excel 或运行中的 Unity Editor。

远端仓库：`https://cnb.cool/nanzhaigame-xpy/MIDALocalizationTool`。

## 从空白开始

- 首次启动没有项目、片段、语言任务或示例对话；导入用户选取的 ZIP 后才显示内容。
- 可以点击「导入 ZIP」或拖入 ZIP。没有任务时不能保存或导出空交付包。
- 只恢复在本独立编辑器中通过 ZIP 导入并保存的工作区；不自动读取或迁入旧编辑器的真实任务、示例、备份和视频，也不删除旧数据。
- 本仓库不包含任何业务 ZIP、视频、翻译输出、自动保存工作区或备份。

## 开发启动

安装 Node.js、Rust 及系统桌面构建工具后，在此仓库根目录运行：

```sh
npm ci
npm run desktop
```

Tauri 调用 `scripts/prepare-desktop.cjs`，将共用界面复制到 `dist/` 后启动原生窗口。开发和构建无需把仓库放在某个固定位置，也不读取原 Unity 仓库。

### 浏览器预览

```sh
python3 serve.py
# 如果 8034 已占用，使用另一个端口
python3 serve.py --port 8035
```

Windows 可用 `py -3 serve.py`。默认只监听 `127.0.0.1:8034`，使用 Python 3.9 或以上，不依赖第三方 Python 包。浏览器导出的 ZIP 默认写入本仓库的 `LocalOutput/`，也可用 `--output <目录>` 指定位置。该目录不提交。

浏览器 IndexedDB 使用独立名称 `mida-localization-editor-workspace`，不读取旧编辑器的数据库。它与原生 App 工作区相互独立；不同来源地址的浏览器工作区也不会自动共享。需要迁移内容时使用 ZIP，不拷贝浏览器缓存。

## macOS 构建

需要 Xcode 构建工具和 `aarch64-apple-darwin`、`x86_64-apple-darwin` 两个 Rust target：

```sh
npm run release:mac
```

生成通用 Apple Silicon / Intel App 与 DMG，最低 macOS 13。产物位于 `src-tauri/target/universal-apple-darwin/release/bundle/`。当前配置使用 ad-hoc 本地签名，不包含 Apple Developer ID 或 Apple 公证，不能将它当作已通过公开发行审核的安装包。

### Windows 构建

macOS 交叉构建需要 `cargo-xwin`、`x86_64-pc-windows-msvc` Rust target、LLVM 与 NSIS。将 LLVM 的 `bin` 加入 PATH 后运行 `npm run release:windows`，生成当前用户安装的 x64 NSIS 安装程序。Windows 原生构建使用 `npx tauri build`，自动采用 `tauri.windows.conf.json`。

Windows 安装程序未进行 Authenticode 签名，尚未在真实 Windows 环境验证安装与启动。缺少 WebView2 时安装程序需要联网下载。

### 应用更新与发布

CNB 自动检查及标签发布配置见 [CI/CD 接入说明](docs/ci-cd.md)：分支 push / PR 自动检查，正式版本标签在专用 Mac Runner 上重新构建双平台产物并发布。首次使用须先完成文档中的节点、签名与仓库配置。

- 正式版启动后自动读取当前公开 CNB 仓库的 Release 列表，忽略草稿与预发布版本；发现新版后弹窗提示，不自动下载或安装。若正在导入、查看历史或使用其他弹窗，会在操作完成并返回编辑器后提示。无网络时显示检查失败，不妨碍离线编辑。
- 每版在 `release-policy.json` 明确配置 `mandatory`（强制）或 `optional`（可选），发布脚本写入 `latest.json` 的布尔字段 `mandatory`，并检查配置与源码快照一致。没有该字段的旧清单按可选更新处理；字段类型错误则报告更新检查失败。
- 强制版没有跳过、稍后、关闭弹窗入口，Escape / 点击遮罩不能关闭；用户仍须主动点击安装，也可以退出应用。安装失败保留弹窗并允许重试。
- 可选版可以「稍后提醒」（下次启动再提示）或「跳过这个版本」（仅跳过该版本的启动提示）。手动「检查应用更新」不受跳过选择影响，新版本和强制策略不受以前的跳过选择影响；清空全部缓存会清除跳过记录。
- 新策略从 0.3.3 客户端开始支持；0.3.0—0.3.2 需先经原有检查更新入口或手动安装升级。既有已发布版本不覆盖重传，后续发布前按新版本号配置策略。
- 用户选择「保存并安装更新」后先保存并备份当前语言空间，再下载平台对应产物，验证签名后安装并重启；开发版和浏览器预览不安装更新。
- 0.3.0 是首个支持更新的版本，旧版需要手动安装一次。更新签名与操作系统发行签名是两回事。
- 构建前设置 `TAURI_SIGNING_PRIVATE_KEY`（受保护的私钥文件路径）和 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`。本机私钥保存在仓库外的 `~/.local/share/mida-localization-release/updater.key`，权限为 600；务必安全备份，不要提交或上传。后续版本必须使用相同私钥。
- CNB Release 附件包含 Mac DMG、通用 `.app.tar.gz`、Windows EXE、两份 `.sig`、`latest.json`、源码快照、构建信息和 SHA256 清单。
- 准备 `releases/<版本>/` 产物后，运行 `npm run release:publish -- releases/<版本> --publish`，仅从已有草稿发布；上传失败不公开半成品。脚本通过 `CNB_TOKEN` 环境变量或 Git credential helper 读取凭据，需要 `repo-release:rw`，不会把发布凭据放入安装包。
- 发布源码以 source 附件及 build-info 中记录的工作目录快照为准；本脚本不会自动提交或推送源码。具体说明见 `docs/release-0.3.0.md`。

## 编辑与交付

### 语言空间

- 「翻译任务」区域可切换空间，或点击「新建语言空间」输入 ZIP 使用的目标语言代码（如 `en`、`zh_tw`、`ja`）。不预建语言任务或示例数据。
- 一个空间只接收一种目标语言。导入其他语言的 ZIP 时，询问是否创建对应空间并导入；取消会丢弃暂存导入，不更改任何空间；确定会自动创建（已有则使用）对应空间、导入并切换。项目身份及版本合并校验针对目标空间执行，不覆盖原空间。包含多种目标语言的 ZIP 仍拒绝导入，请从来源分别导出单语言 ZIP。
- 「偏好 → 清空所有的缓存」弹出「确定要清空？」确认框。取消不执行清理；确定后永久删除当前编辑器所有空间的任务、译文、草稿、历史自动保存、备份和视频缓存，返回空白状态。不会删除原始 ZIP、已导出文件或其他编辑器的数据。浏览器仅能清理当前来源地址的 IndexedDB 和该预览服务的媒体缓存，无法清理其他浏览器或来源地址的存档；桌面 App 与浏览器存档独立。清理期间停止自动保存，其他同源编辑页面会暂停操作并提示刷新；清理失败会明确提示并停止旧数据回写，可重试。
- 空间独立保存任务、未确认草稿、版本合并状态、布局、备份和预览视频。切换前先保存；保存失败时停留在原空间。更新同片段视频只清理当前空间的旧媒体。
- 本编辑器原有工作区保留在原位置，作为已有语言空间显示，不扫描或迁入其他编辑器数据。新空间使用独立存储；跨空间交付仍使用原始 ZIP 项目身份，不修改导出协议。
- 桌面新空间保存在本应用数据目录的 `spaces/<语言代码>/`；浏览器存档使用独立键，媒体位于本机输出目录的 `.spaces/<语言代码>/`。每个空间分别保留最近 10 份备份。

### 交付流程

1. Unity 导出本地化 ZIP，包含清单和每片段独立的 JSON；可附带预览视频及对话包时间映射。
2. 编辑器导入 ZIP，按片段和目标语言呈现任务。默认预览中文与译文，点击编辑后修改，点「确定」退出编辑。

   片段列表顶部可选择「全部显示」（默认）或「仅未修复」；未修复指仍有待确认内容或编辑中草稿的片段，全部确认后会自动从筛选结果中隐藏。片段按名称中的数字自然排序，例如 C0P1、C0P2、C0P10、C1P0、C1P2。筛选随语言空间保存，不切换当前编辑内容，也不改变交付勾选；「全选交付任务」仍作用于当前空间的全部任务。

3. 同一项目导入新版本时匹配已有词条；中文基线相同则复用已有译文，变化则保留译文并标记待处理。
4. 支持对话包收起、中英文摘要与待处理提示；仅当视频可用且含该包节点时显示「查看视频」。视频区默认隐藏，点击「查看视频」才显示，默认位置为右侧，可在「偏好 → 视频预览位置」切换到下方。拖动分隔线调整空间，拖到最右侧（下方布局拖到底部）自动隐藏并暂停视频；再次查看时恢复拖动收起前的大小。视频保持原比例完整显示，位置及两种布局的大小随工作区保存，但启动或恢复工作区时不会自动展开。
5. 选择交付任务后导出数据 ZIP，由 Unity 负责回收与覆盖。编辑器只导出数据，不录制或回传视频。

文件结构、版本及容量边界见 [ZIP 协议](docs/package-format.md)。Unity 的录制实现仍属于 Unity 仓库，不移动到本项目。

## 保存与备份

- 「偏好 → 自动下一条」默认关闭，随当前空间保存。开启后，确认一条译文会自动进入当前任务的下一条待处理内容，展开所属对话包、聚焦译文并短暂高亮；会清除搜索并切换到待处理筛选，末尾回查前面的待处理条目，全部完成后停止。系统启用减少动态效果时使用静态高亮代替闪烁。

- 「偏好 → 自动保存间隔」默认沿用停止编辑 800 毫秒后保存、持续编辑约每 5 秒保存；可改为 5 秒、10 秒、30 秒、1 分钟、2 分钟或 5 分钟。自定义间隔从首次未保存修改或上次保存尝试开始计时，不因持续输入延后，界面每秒检查一次。设置随当前语言空间、备份及历史恢复，旧存档自动使用默认配置；备份保留间隔不变。
- 未保存时，「翻译任务」标题右上角显示 `*`，保存按钮为红色；保存成功且没有更新的修改时，星号消失、按钮变灰。底部不再滚动显示自动保存时间与状态；保存失败仍显示错误并保留未保存标识。历史只读查看不显示未保存标识。
- 底部「保存」或 Command/Ctrl+S 可立即保存，切换空间、导入、更新、页面隐藏和退出前的保护保存不受自动保存间隔影响。
- 保存已确认译文、未确认输入、版本信息及编辑布局；未点「确定」的内容不会被自动确认。
- 每次导入覆盖前，先在被覆盖的空间生成备份（包含尚未确定的草稿）；备份失败则不继续覆盖。空白空间没有旧数据，首次导入后建立首份备份。
- 保留最近 10 份本机备份，在「偏好 → 历史记录与自动备份」中查看或回退；这不代替独立设备备份。
- 「查看（只读）」显示历史文本及当时的草稿，不允许编辑、确认译文、导入、导出或保存，不会覆盖当前最新存档。可浏览任务、搜索与展开对话；点击顶部「返回当前最新版本」恢复编辑。
- 「回退」及顶部「回退为此历史记录」均弹出二次确认；取消不回退，确定后先备份当前最新内容，再把所选历史设为当前可编辑版本。回退保存失败不会切换到可编辑历史；未确认草稿仍需手动确定，已清理的视频不会恢复。
- 独立 App 标识为 `com.mida.localization.editor`，macOS 原生数据位于 `~/Library/Application Support/com.mida.localization.editor/workspace/`，不与旧编辑器共享。旧目录 `~/Library/Application Support/com.mida.localization/` 保持原样、不自动读取；旧任务需要通过 ZIP 手动导入。无需将这些目录放入 Git。
- 导入同一片段的新任务成功后清理旧媒体，新包没有视频也会清理。取消或保存失败保留旧媒体，其他片段不受影响。备份只保留媒体引用，不恢复已删除的视频。
- 磁盘空间不足、版本冲突或保存失败会显示错误，不假报保存成功。

## 关于

- 从 1.0.0 起，用户可见的更新说明只写本次改进，不混入下载步骤、签名、公证、构建或源码发布细节。发布者仍在本 README 中维护技术说明；`docs/release-<版本>.md` 用作用户可见的发布正文与更新清单内容。旧版本历史在界面中显示对应的简短摘要，不重写远端历史版本。

- 侧栏「关于」替代原「帮助」，每次打开默认选中「仓库」模块；原帮助内容完整保留在「使用说明」中。
- 「仓库」显示本项目 CNB 地址并支持复制，在线读取最近 5 条正式 Release，按发布时间倒序显示版本、发布时间和更新说明。不足 5 条时只显示已有记录，不补占位版本。
- 桌面与浏览器预览均支持读取历史；读取失败会显示错误和重试按钮，不影响切换到使用说明。远端更新说明按纯文本显示，不执行其中的 HTML。此界面不修改本地工作区或备份。
